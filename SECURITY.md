# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Email security reports to the maintainers via GitHub private vulnerability reporting on the repository, or open a draft security advisory if you are a collaborator.

Include:

- Description of the issue and potential impact
- Steps to reproduce
- Affected versions or commits

We aim to acknowledge reports within 5 business days.

## Scope

In scope: GraphScope API, desktop app, and official release artifacts. Out of scope: third-party GraphQL endpoints you configure as environments.
